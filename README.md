# Rezerv

Pocket money you can see. A web app for the Dezerv Children's Day Hackathon 2026 that helps kids:

1. **See where their money went**, measured in days of their own pocket money or in things they love (they can add their own).
2. **Save for a goal**: a 3D cycle builds itself piece by piece as they save, and a temptation check shows how many days a treat pushes the goal back.
3. **Ask a grown-up before buying.** A grown-up creates a private Parent PIN (stored only as a salted hash) to unlock their corner and approve, decline or talk it through.
4. **Freeze a want for 24 hours** before deciding (the out-of-the-box idea).

Made-up money only. No sign-in, no personal info, and everything stays in the browser (localStorage).

Built with React, Framer Motion and React Three Fiber.

```bash
npm install
npm run dev
```
